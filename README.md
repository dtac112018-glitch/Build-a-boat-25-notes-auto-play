# 🎵 Build A Boat 25-Note Player

A 25-note music player and keyboard cue mapper for **Build A Boat for Treasure** on Roblox.

## ✨ Features

- 🎹 A 25-note musical setup.
- ⌨️ Keyboard cue mapping for musical inputs.
- 🎶 Experiment with melodies using in-game Music Note blocks.
- 🛠️ Designed for players who enjoy building music setups.

## 🧱 Building the 25-Note Setup

Follow this guide to build the music setup inside Build A Boat for Treasure.

### What you'll need

- 25 Music Note blocks.
- A Car Seat to control your notes.
- The Property Tool to configure note pitches.
- The Binding Tool to assign keyboard controls.

*You may need to obtain some of these items from the in-game Shop.*

### Step 1 — Build a platform

1. Enter your Building Space.
2. Use the Building Tool to place a small, stable platform.
3. Leave enough room to arrange and access all 25 Music Note blocks.
4. Place a Car Seat where you can easily sit and test your setup.

### Step 2 — Place the Music Note blocks

1. Find Music Note blocks in your inventory.
2. Place all 25 blocks on your platform.
3. Arrange them in a **5 × 5 grid** to keep the notes organized.
4. Leave the notes accessible so you can select them individually.

### Step 3 — Set the pitches

1. Equip the Property Tool.
2. Select a Music Note block.
3. Find its **Key** property.
4. Choose the desired pitch.
5. Repeat for all 25 blocks, checking each note's displayed pitch.

The game's Music Note blocks support 25 pitches, from F#3 through F#5. Make sure your notes are configured as intended before assigning keyboard controls.

### Step 4 — Use the Q–N keyboard layout

The 25-note setup uses these keyboard keys in order:

`Q W E R T Y U I O P A S D F G H J K L Z X C V B N`

Each key corresponds to one of the 25 notes, from the lowest pitch to the highest.

### Step 5 — Test your setup

3. Check that the corresponding note plays.
4. Test every note individually.
5. Correct any pitches or bindings that don't match your mapping.

Save your build if the game provides a save option for your plot.

## 🔊 Optional Experiment: 50 Music Note Blocks

Want to experiment with a fuller sound?

1. Add a second Music Note block for each of the original 25 pitches.
2. Configure each additional block to match its corresponding original pitch.
3. Bind the duplicates to the same keyboard input as their matching notes, if the game's binding system permits it.
4. Test one duplicated note before expanding the whole setup.

**Important:** Duplicate blocks may change how the sound blends or how loud it seems nearby, but increased volume or range is not guaranteed. Test with another player before building all 25 duplicates.
