# 🎵 Build A Boat 25-Note Player

A 25-note music player and keyboard cue mapper for **Build A Boat for Treasure** on Roblox.

Speaker Cue Mapper helps you organize keyboard cues for your in-game music setup, making it easier to play musical sequences using your notes.

> **Status:** Community project  
> **Platform:** Windows (if supported by your current build)  
> **Game:** Build A Boat for Treasure

## ✨ Features

- 🎹 **25-note setup** — designed around a 25-note musical range.
- ⌨️ **Keyboard cues** — associate keyboard inputs with musical notes.
- 🎶 **Music experiments** — create and test musical sequences in your Build A Boat setup.
- 🛠️ **Made for builders** — intended for players who enjoy creating music with in-game blocks.

## 🎼 How It Works

The project is designed around a 25-note music setup. Keyboard cues help connect your inputs with the corresponding notes in your Build A Boat arrangement.

Tested in Windows 11 26H2 (amd64).

For the best results, make sure your keyboard mappings match the positions and pitches of your in-game note blocks.
